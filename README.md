# 🏡 WanderLust - Airbnb Clone

WanderLust is a full-stack Airbnb-inspired web application developed as part of my Sigma 5.0 Full Stack Web Development journey. The project allows users to browse travel listings, with additional features such as authentication, CRUD operations, reviews, image uploads, maps, and deployment being added progressively as the project evolves.

This repository documents my learning journey by implementing real-world web development concepts using the MERN ecosystem (Node.js, Express.js, MongoDB) along with EJS for server-side rendering.

## 🚀 Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- EJS
- Bootstrap
- JavaScript
- HTML5
- CSS3

## ✨ Features Implemented

- Complete CRUD Operations (Create, Read, Update, Delete)
- RESTful Routing
- MongoDB Database Integration (Mongoose)
- EJS Templates with EJS-Mate Layouts
- Bootstrap Responsive UI
- Server-side Validation using Joi
- Client-side Form Validation
- Custom Validation Middleware
- Custom ExpressError Class
- Global Error Handling Middleware
- Async Error Handling using wrapAsync
- Custom Error Page (error.ejs)
- Method Override for PUT & DELETE Requests
- Clean Project Structure
